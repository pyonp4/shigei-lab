# 研究紹介ページを作る

ルールはすべて、リポジトリ直下の `RESEARCH_GUIDE.md` にある。最初にそれと `docs/research1.html`（HTML の部品と文体のお手本）を読み、そのとおりに作る。
節の構成は `RESEARCH_GUIDE.md` の「2. ページの構成」に従う。お手本にある「今後の展望」「研究業績」の節は作らず、工夫した点や難しい点も書かない。

1. `RESEARCH_GUIDE.md` の「1. 用意するもの」の質問のうち、まだ答えがないものをまとめて質問する。Google フォームの回答を貼ってもらってもよい。図の画像は、ファイルのパスを教えてもらう。
2. 「2. ページの構成」「3. 文章のルール」に従い、日本語と英語（`data-en`）の原稿を書く。答えにない数値や成果は書かず、`<span class="todo">【要確認：〇〇】</span>` で残す。
3. 「5. ページにする手順」に従い、`docs/research1.html` をコピーして新しいページを作る。7（研究分野）の答えに合う欄へ `docs/research.html` のカードを追加し、`README.md` の表も更新する。
4. 画面幅 1280px と 375px で表示を確かめ、「6. 公開前チェック」の結果を報告する。

作業は `CLAUDE.md` のブランチ運用に従う（main で作業しない）。
