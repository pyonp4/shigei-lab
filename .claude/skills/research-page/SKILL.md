# 研究紹介ページを作る

ルールはすべて、リポジトリ直下の `RESEARCH_GUIDE.md` にある。最初にそれと `docs/research1.html`（お手本）を読み、そのとおりに作る。

1. `RESEARCH_GUIDE.md` の「1. 用意するもの」の質問のうち、まだ答えがないものをまとめて質問する。論文やスライドがあれば受け取る。
2. 「2. ページの構成」「3. 文章のルール」に従い、日本語と英語（`data-en`）の原稿を書く。材料にない数値や成果は書かず、`<span class="todo">【要確認：〇〇】</span>` で残す。
3. 「5. ページにする手順」に従い、`docs/research1.html` をコピーして新しいページを作る。`docs/research.html` へのカード追加と、`README.md` の表の更新も行う。
4. 画面幅 1280px と 375px で表示を確かめ、「6. 公開前チェック」の結果を報告する。

作業は `CLAUDE.md` のブランチ運用に従う（main で作業しない）。
